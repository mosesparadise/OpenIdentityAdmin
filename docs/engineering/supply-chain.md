# Dependency and license evidence

Dependencies are centrally pinned and restored with lock files. CI rejects incomplete advisory reports, known vulnerable direct/transitive NuGet dependencies, unknown license declarations, changed reviewed license texts and detected credentials in the current source snapshot. Actions and the Gitleaks binary are pinned to immutable hashes. A clean scan is evidence for those tools and feeds at that time, not proof that vulnerabilities or secrets cannot exist.

`python3 scripts/check_supply_chain.py licenses artifacts/security/licenses.json` inventories the locked NuGet graph and package content hashes. It is not yet a complete product SBOM: the later React graph, runtime/container OS packages, installed tool binaries and final deployment artifacts must be included before release. No React dependencies exist in this foundation slice.

The xUnit v3/MTP inventory contains 209 package/version pairs (the initial foundation contained 205). `eng/license-policy.json` records permissive expressions and exact text hashes for three exceptions. Fractions has BSD-2-Clause text. The SQL client native runtime and MSAL NativeInterop include Microsoft proprietary terms; their applicable redistribution/end-user obligations remain a public-release legal review item. The xUnit v3 packages declare Apache-2.0; xunit.abstractions and its legacy URL-only exception were removed with the v2 graph. Recording these exceptions permits tracked development; it does not grant legal clearance or make every dependency open source.

Third-party template attribution for the pinned GitHub Spec Kit integration is preserved in `docs/third-party/`. The repository owner has not selected a license for original project code; this change does not choose one implicitly. The product release checklist must resolve that decision and distribute required third-party notices. SQL Server production licensing is an operator obligation; local disposable containers are development/test use.

Initial local verification on 10 October 2026 reported no known vulnerable packages across all 16 solution projects. CI must refresh advisory evidence on each change. Source scanning covers the current checkout, including proposed additions, not the entire historical Git object database. Test reports use synthetic data; secrets and generated local artifacts are excluded from the scanned/published source snapshot.

Feature 004 adds OpenIddict's ASP.NET Core server integration, an independent JWT validator for the test relying party, pinned Playwright and axe accessibility automation. Deque.AxeCore.Playwright is MIT; its unmodified Deque.AxeCore.Commons dependency embeds the MPL-2.0 accessibility engine. Its exact license text is inventoried as a test-only reviewed exception. Retain notices and satisfy applicable source-availability obligations when distributing that dependency. Browser binaries/OS dependencies remain part of the later full artifact SBOM; the installer package alone is not their license inventory.
