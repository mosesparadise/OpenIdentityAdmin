## Recommendation and alternatives

Recommend this bounded sequencing exception only after the reviewed diagnostic revision passes its entire exact-head matrix and T033/T034/T035 are delivered. The three causes remain unknown. In particular, the WebKit failure demonstrates missing certificate-specific evidence, not successful acceptance of an untrusted certificate. That distinction does not establish harmlessness: certificate reliability remains an explicit security-relevant acceptance and release blocker. The proposed internal governance work adds no browser trust changes or externally reachable management surface. Developing those missing authority protections under strict regression gates is a bounded tradeoff; later BFF/API activation still requires its separate prerequisites and acceptance.

Independent architecture and security reviewers conditionally support presenting this explicit three-finding decision subject to this proposal PR passing its own required checks. A green result supports only that execution, never causal closure. A recurrence or new failure holds the proposal for evidence-based disposition before approval. No further identical passing run or unrelated cleanup is presented as a cure.
The stricter alternative is to hold T020/T021 until all three historical causes and all manual observations are resolved. It avoids advancing through unresolved acceptance but may stall internal security work indefinitely if the original missing evidence cannot be recovered. More unrelated cleanup or repeating identical passing runs does not resolve that tradeoff.
