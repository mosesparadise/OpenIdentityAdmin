# Dashboard contract

The named Development-only local-demo profile exposes `Initialize administrator` on its initializer resource. It requests username and masked password inside authenticated Aspire interaction. The callback rejects unavailable interaction, non-running/foreign resource, generic supplied command arguments, invalid input and concurrent/terminal invocation. Username is 1–128 ASCII letters/digits or ._@-; password is16–256 characters; serialized bootstrap is at most4096 UTF-8 bytes. Native Identity still validates its policy.

Only successful ordered pending-account bootstrap/public registration/revision-one upgrade reports completion. Errors are fixed and never include command stdout/stderr, raw exceptions or inputs. Uncertain mutation is terminal and stops the owned initializer. A fresh complete graph is required after failure. Real MFA enrollment and fresh sign-in remain user actions.
