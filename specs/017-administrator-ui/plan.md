# Implementation plan — visible administrator workspace

## Technical context
Existing .NET10 BFF/Aspire; React19.3.1, TypeScript5.9.3 (existing compatible generator constraint), Tailwind4.3.3, RadixSlot1.5.0 and esbuild0.28.2. Native system fonts, shared semantic CSS tokens, no CDN. New application package lives in the already approved src/frontend hierarchy. Cookie-authenticated read-only generated BFF browser contract; no persistence changes.

## Architecture and decisions
- src/frontend/IdentityPlatform.Admin.Ui contains Features/Shell, Features/Session and small accessible primitives. Two exact routes `/` and `/session`; ordinary links preserve browser navigation/history with no broad SPA fallback.
- Build immutable static assets into `generated/`, including exact local dependency notices. Commit these generated bytes and embed them in BFF; ordinary .NET builds and local-demo Docker builds require no Node. A required frontend CI job performs locked install, type/behavior checks, advisory/license inventory and byte-for-byte regeneration verification.
- Explicit local-demo composition installs AdminUi before remaining routing. Static HTML/assets contain no identity. Exact allowlisted GET/HEAD paths only, bodyless/no-query requests, strict CSP, no inline allowances, no remote assets, no-store documents and exact types/nosniff. Unknown paths continue normal404/protocol handling. No arbitrary file serving.
- BrowserSession presentation gets an optional fixed workspace navigation marker, registered only with the shell. Callback publication returns to `/` only in that composition; all existing cookie/commit/disposal checks remain. Login/logout pages gain fixed workspace links without arbitrary return inputs.
- Read status through generated types/openapi-fetch, credentials same-origin, cache no-store, redirect error. Validate runtime shape/size/date and strict expiry before showing identity. Generation/cancellation fences prevent old responses winning; abort on unmount/pagehide, clear identity while rechecking or on failure. No polling/automatic renewal; explicit recheck and initial load only. A local expiry timer removes the stale observation but never establishes server denial or permission.
- Native select theme control stores only the existing identity-theme preference; early external bootstrap establishes palette before React paint, React owns events and storage/system changes. RadixSlot supplies the shadcn-style button composition without inline positioning styles.

## Constitution check
