## Native compatibility correction

Protected state is validated using global local credentials before registration resolution, so this dereference can throw. `NativeClientStateValidation` delegates unchanged native validation and supplies an empty temporary registration only for an unresolved, exclusively state-token context. It restores the original registration in `finally`, including exceptions. It introduces no keys, issuer, metadata endpoint, configuration manager, exception suppression or retry. Native descriptor filters and order are imported. Reassess this narrowly scoped workaround when upgrading the library.

## Explicit HTTPS cancellation

`NativeClientCancellationTests` adds PostgreSQL/SQL Server × PAR/token controls. Each requires a positive native HTTPS exchange first, then pauses exactly one POST before issuer protocol processing. Client state has already been created (PAR) or consumed (token). It initiates explicit client cancellation while the operation is pending and independently observes the original Kestrel request-aborted token before cleanup. One monotonic five-second observation budget covers readiness, cancellation and completion; the unchanged production/native timeout is ten seconds.

The shared pause atomically distinguishes initiation from premature server cancellation. Release alone cannot manufacture cancellation evidence, and every exit terminates interception without falling through to issuance. Four pure controls cover explicit cancellation, premature cancellation, cleanup-only release and exact one-shot method/path matching. Client and server work are joined on failure; the original failure is preserved.

Provider controls require actual boundary abort, no authentication/body/location/cookies, no extra PAR/token sends, unchanged native issuer token/authorization row counts, and the expected durable state status. Token callback replay from another existing root must be rejected without resending. This scope proves cancellation before issuer processing, not cancellation inside an issuer database transaction or after commit. These are additional provider cases; hosted execution of this source remains pending.
