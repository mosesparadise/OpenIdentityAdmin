## Implementation and evidence boundaries

One explicit ProtocolStorageRequest captures the monotonic clock, original cancellation and ten-second deadline before acquiring any child scope. Sequential operations use fresh scoped contexts while borrowing the same absolute deadline. Each child owns its existing local cancellation resources; successful child cleanup cannot cancel a later child. An owner fault, overlapping request operation, original cancellation, expired budget or cleanup failure makes the enclosing request terminal. No fresh scope can erase a swallowed native failure.

The enclosing RunAsync awaits the actual callback and owns cleanup in finally. Thin opt-in server/client dispatcher decorators forward to the installed native dispatcher, guard request cancellation/time before and after dispatch, and retain the original native handled/skipped/rejected flags. They do not commit or dispose the enclosing scope when a dispatch returns. OpenIddict 7.7.1 BaseContext cancellation proxies to its Transaction; nested linked-token substitution must restore its parent binding in finally. A separate activity tracker retains outstanding dispatch tasks through child-scope cleanup without confusing them with exclusive EF execution or waiting on a dispatcher from transaction cleanup inside its own handler.

Permanent controls cover fresh contexts at original deadline minus/equal/plus boundary; one-second remaining phase budget at age nine; swallowed failure and overlap; actual installed server/client dispatcher nested, handled/skipped/rejected/error/throwing paths; native ASP.NET request-to-error flow where feasible; token restoration and unexpected mutation; outstanding work containment; and both-provider native fresh-scope commit/rollback with one original request. The four existing provider/store cells retain their identities and gain real native-manager checks for sequential fresh-scope commit/rollback, commit inside an active dispatch leaf with phase cleanup before return, and rejected commit while another dispatch remains pending.
