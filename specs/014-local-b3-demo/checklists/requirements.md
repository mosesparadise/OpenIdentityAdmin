# Requirements quality checklist

- [x] Windows-only orchestration and disposable lifecycle explicitly selected by user.
- [x] Local activation bounded by Development and distinct from production/public release.
- [x] Credential transport/storage and privileged Docker metadata exposure documented.
- [x] No bootstrap password/configuration shortcut or active-account fixture.
- [x] Canonical TLS and owned native dispatch are acceptance criteria.
- [x] Both providers, default denial, unsafe paths, cancellation, restart and disposal have tasks.
- [x] Architecture review resolves generic-host pipeline before source changes.
- [x] Windows execution is distinguished from Linux CI; no unexecuted pass claimed.
